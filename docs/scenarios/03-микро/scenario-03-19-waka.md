# 03.19 `/waka`

> Просмотр WakaTime статистики рабочего времени (только для подключённых).

---

## Обзор

| Параметр | Значение |
|----------|----------|
| Команда | `/waka` |
| Вид | Микро (C) |
| Файл | [`handlers/commands.py:186`](../../../handlers/commands.py) |
| Требования | Онбординг + активное WakaTime подключение |
| Связанное | [`/wakatime`](scenario-03-20-wakatime.md) — управление подключением |

---

## 1. Триггер и ветки

| Состояние | Что видит user |
|-----------|----------------|
| Не подключён | «Подключите WakaTime через /wakatime» |
| Подключён | Сводка за день/неделю: языки, проекты, общее время |

## 2. Содержимое (при подключении)

- **Сегодня:** часы / топ-3 языка / топ-2 проекта
- **Неделя:** часы / daily average / streak
- **Тренд:** сравнение с предыдущей неделей (↑↓)

## 3. Источники

| Что | Откуда |
|-----|--------|
| API key | `wakatime_connections` таблица (или аналог) |
| Stats | `clients/wakatime.get_summary(api_key)` |

## 4. Ключевые файлы

| Файл | Назначение |
|------|-----------|
| `handlers/commands.py` | `cmd_waka` (роутер на `/waka`) |
| `clients/wakatime.py` | API calls |

## 5. Различение `/waka` vs `/wakatime`

- **`/waka`** — просмотр статистики (одноэкранный showcase)
- **`/wakatime`** — управление подключением (OAuth, status, disconnect)
