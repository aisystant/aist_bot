# 03.39 `/erase_me` — удалить свои данные из «Аналитика чата»

> Участник закрытого чата, где работает «Аналитик чата», сам удаляет свои
> сообщения из архива и отключает дальнейший сбор. Решение пилота 03.11:
> удаление инициирует только сам участник, подтверждение — кнопкой «Удалить».
> Бот — тонкий клиент: удаление делает сервис `chat-analyst-service`
> (`POST /participants/{id}/erase`, CONTRACT.md), бот только спрашивает
> подтверждение и передаёт номер нажавшего.

---

## Обзор

| Параметр | Значение |
|----------|----------|
| Команда | `/erase_me` — только личка с ботом |
| Тип | Микро (C) — одна команда, одно сообщение с кнопками (подтверждено пилотом 03.11) |
| Файлы | [`handlers/chat_analyst.py`](../../../handlers/chat_analyst.py) — `cmd_erase_me`, `cb_erase_me`, общая `_run_self_action` (с `/resume_me`, сценарий 03.40); [`clients/chat_analyst.py`](../../../clients/chat_analyst.py) — `erase_participant` |
| Доступ | Любой человек; удаляются только его собственные данные (`callback.from_user.id`) |
| Включение | Те же переменные `CHAT_ANALYST_*`, что у сбора; без них — «сейчас недоступно» |

---

## Поток

1. Участник пишет `/erase_me` в личке. Аргументы команды игнорируются.
2. Бот объясняет, что удалится (все сообщения человека из архива во всех закрытых чатах, сбор отключится, вернуть его можно командой `/resume_me`, удалённые сообщения не вернутся) и что не удалится (копии сводок у наставников в Telegram, сводка, составлявшаяся в момент удаления), даёт ссылку на условия и кнопки «Удалить» / «Отмена».
3. «Отмена» → «Отменено, ничего не изменилось». Сервис не вызывается.
4. «Удалить» → бот сразу отвечает на нажатие, убирает кнопки, вызывает сервис с номером нажавшего (до трёх попыток при сетевой ошибке, 5xx и 429).
5. Успех → «Данные удалены, сбор ваших сообщений отключён» — один и тот же текст, сколько бы сообщений ни удалилось.
6. Сервис не подтвердил → «Не удалось подтвердить удаление: сервис не ответил. Повторите /erase_me позже — повтор безопасен». Бот не пишет «не удалено»: после таймаута сервис мог удалить, а ответ потеряться.

## Граничные случаи

| Случай | Поведение |
|--------|-----------|
| `/erase_me` в группе | Бот молчит и не отдаёт событие дальше: никто не ответит в чат |
| Кнопку нажали повторно или через неделю | Сервис вызывается снова; повтор безопасен |
| Не удалось убрать кнопки | Записывается в журнал, удаление продолжается |
| Нажатие пришло не из лички | Нажатие подтверждается, сервис не вызывается |

## Журнал

Только коды ответа сервиса (`erase unconfirmed status=…`) и факт удаления, без номера человека.
