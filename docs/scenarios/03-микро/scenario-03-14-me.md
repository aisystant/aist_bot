---

## 1. Триггер и ветки

| Tier | Содержимое |
|------|-----------|
| **T0-T1** | Базовый профиль + локальная статистика бота (streak, марафон) |
| **T2** | + Подписочная активность (Aisystant данные) |
| **T3+** | + Полный ЦД-контекст через `gateway_mcp.get_user_profile()` |

## 2. Содержимое

**Секции (сверху вниз):**
1. **Profile** — имя, занятие, роль, цели из `public.users`
2. **Activity stats** — из `development.user_state` + `activity_log`:
   - Активных дней (всего / streak / рекорд)
   - Последняя активность
3. **Marathon progress** — если есть `marathon_status`:
   - День / всего тем / выполненных
   - Catch-up / отставание
4. **Feed progress** — если есть `feed_status`:
   - Дайджестов / фиксаций / текущая неделя
5. **ЦД-раздел (T3+)** — ключевые derived-индикаторы (не вычисляются в боте)

## 3. Источники

| Что | Откуда |
|-----|--------|
| Profile | `public.users` |
| Activity | `development.user_state`, `activity_log` |
| Marathon/Feed | `answers`, `feed_sessions` |
| ЦД (T3+) | `gateway_mcp.get_user_profile()` |

## 4. Ключевые файлы

| Файл | Назначение |
|------|-----------|
| `handlers/twin.py` | `cmd_me` (отдельный handler от `/twin`) |
| `db/queries/dev_stats.py` | Агрегация activity/progress |
| `clients/gateway_mcp.py` | T3+ ЦД-чтение |

## 5. Правило anti-hallucination

При T0-T1 (нет ЦД) секция «Цифровой двойник» НЕ показывается — вместо неё кнопка «Подключить ЦД». Claude НЕ должен генерировать числа из косвенных источников (см. `/twin` §3).
