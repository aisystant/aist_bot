# 03.06 `/about`

> Сводный экран «о боте»: назначение, платформа, экосистема, tier-aware кнопки действий.

---

## Обзор

| Параметр | Значение |
|----------|----------|

| Вид | Микро (C) — одноэкранный |

| Pack-сущность | DP.AISYS.014 (идентичность бота) |

---

## 1. Триггер и маршрут

- Пользователь вводит `/about` → `handlers/info.py → cmd_about`
- Handler собирает tier пользователя через `detect_ui_tier()` и рендерит i18n-текст с tier-aware кнопками

## 2. Содержимое сообщения

**Текст:** из i18n (`t('info.about_*')`) — несколько параграфов: про бота, платформу Aisystant, экосистему IWE, источники знаний.

**Кнопки (tier-based):**

| Tier | Кнопки |
|------|--------|
| **T0** | `[Запустить марафон]` `[Узнать про Aisystant]` |
| **T1** | `[Запустить марафон]` `[Про подписку]` |
| **T2+** | `[Марафон]` `[Лента]` `[Тренировка]` `[Купить подписку]` |

## 3. Источники данных

| Что | Откуда |
|-----|--------|
| Tier пользователя | `detect_ui_tier(chat_id)` — см. `CLAUDE.md § 12 Progressive UI` |
| Текст | i18n `t('info.about_intro')`, `t('info.about_platform')`, `t('info.about_ecosystem')` |
| Ссылки | `PLATFORM_URLS` из `config/settings.py` |

## 4. Ключевые файлы

| Файл | Назначение |
|------|-----------|
| `handlers/info.py` | `cmd_about` handler |
| `core/tier_detector.py` | `detect_ui_tier()` |
