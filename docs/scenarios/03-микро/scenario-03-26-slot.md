# Сценарий 03-26: /slot

**Категория:** микро (вид C, см. CLAUDE.md §4.2)
**Что делает:** записывает реально потраченное время на саморазвитие за сегодня.
**Источник в RCS:** bh.inv (Инвестиционность времени, FORM.089 §12.2).
**WP:** WP-310 Ф13b

## Поток

### С аргументом
```
/slot 1.5
→ Бот: «✅ Записал 1.5 ч саморазвития сегодня.
         За последние 7 дней: X ч.
         Цель на ступени N: Z ч/нед.»
```

### Без аргумента
```
/slot
→ Бот: «Сколько часов саморазвития сегодня?»
  [0.5] [1] [1.5] [2] [3] [4] [Свой ввод]

→ Выбор кнопки N → та же сводка
→ «Свой ввод» → «Введи число часов:» → ввод текстом → сводка
```

### Нет аккаунта (user_uuid = None)
```
→ Бот: «Сначала привяжи аккаунт через /start.
         Без привязки время не учтётся в твоей ступени.»
```

## Событие в Activity Hub

| Поле | Значение |
|------|---------|
| event_type | `slot_logged` |
| payload.hours | введённое число float |
| payload.source | `active` |
| payload.confidence | `measured` |
| activity_domain | `practice` |

## Формат аргумента

Принимает: `1.5`, `1,5`, `2ч`, `2 часа`. Диапазон 0.1–24.
