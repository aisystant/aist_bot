# Scenario 03-32: IWE Dialog Entry (`/iwe`, `.`-prefix)

**Вид:** C (Микро) — команда без FSM-состояний, один ответ  
**Хендлер:** `handlers/iwe.py` `on_iwe`  
**РП:** WP-428 Ф2  
**Service Clause:** DP.SC.183 (draft)

## Триггеры

| Триггер | Пример |
|---------|--------|
| Команда `/iwe` + запрос | `/iwe что такое системное мышление?` |
| Точечный префикс `.` + запрос | `. объясни конвейер разработки` |

## Пользователи и тиры

| Тир | Поведение |
|-----|-----------|
| T3+ (IWE подключён) | `hermes_chat` через Aisystant MCP — полный контекст пользователя |
| T1-T2 (нет IWE) | Haiku-ответ без персонального контекста, ≤300 токенов |
| Без онбординга | Сообщение «Сейчас недоступен» |

## Блокираторы (SkipHandler)

- Активная SM ждёт ответа (`_sm_is_expecting_reply`)
- Фиксация дайджеста (`FeedDigestState.is_waiting_fixation`)

## Privacy guard (DP.SC.183)

| Паттерн | Действие |
|---------|---------|
| `cp\.xxx=` (оценки профиля) | Блокировать ответ → заглушка |
| `@user@domain` (email) | Блокировать ответ → заглушка |
| `WP-\d+` (номер задачи) | Логировать, не блокировать |

## SLA

- T3+ через `hermes_chat`: timeout 60s; `keep_typing` активен
- T1-T2 через Haiku: ~3-5s; `keep_typing` активен

## Ошибки

| Ситуация | Сообщение пользователю |
|---------|----------------------|
| `hermes_chat` упал | «Сейчас недоступен. Попробуй позже.» |
| Haiku упал | «Сейчас недоступен. Попробуй позже.» |
| PII в ответе | «Не могу ответить на этот запрос. Попробуй переформулировать.» |
| Пустой запрос | «Напиши вопрос: /iwe <вопрос> или . <вопрос>» |
