# 03.22 `/link`

> Привязка Aisystant LMS аккаунта к боту: автопоиск по Telegram ID или ручная привязка.

---

## Обзор

| Параметр | Значение |
|----------|----------|
| Команда | `/link` |
| Вид | Микро (C) |
| Файл | [`handlers/link.py:42`](../../../handlers/link.py) |
| WP | WP-181 (склейка платежей семинара) |

---

## 1. Триггер и ветки

| Состояние | Что видит user |
|-----------|----------------|
| Не привязан | Кнопка `[🔗 Привязать аккаунт]` + автопоиск по `telegram_id` |
| Привязан | `aisystant_id`, `email` + кнопка отвязки |
| Автопоиск нашёл | Confirm «Это вы?» → UPDATE `public.users` |
| Автопоиск не нашёл | Инструкция ручной ссылки (code из Aisystant UI) |

## 2. Поля в `public.users`

См. [tables.md §1.1](../../data/tables.md):
- `aisystant_id` — ID в LMS
- `aisystant_linked_at` — когда привязано (timestamp)

## 3. Tier-эффект

После успешной привязки:
- T0 → T1 (если нет подписки)
- T0 → T2 (если есть «Инженерия интеллекта» на Aisystant)

Это детектируется `detect_ui_tier()` при следующем вызове.

## 4. Ключевые файлы

| Файл | Назначение |
|------|-----------|
| `handlers/link.py` | `cmd_link` |
| `clients/aisystant.py` | LMS API (автопоиск по Telegram ID) |
| `db/queries/users.py` | UPDATE `aisystant_id`, `aisystant_linked_at` |

## 5. Связанное с WP-181

Склейка платежей семинара: когда user оплачивает через Aisystant checkout с указанным Telegram ID, автопоиск находит совпадение и привязывает автоматически при первом `/link`.
