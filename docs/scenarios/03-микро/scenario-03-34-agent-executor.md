# Сценарий 03-34: /agent — выбор движка агентной сессии

> Вид C (микро). Источник: WP-428 Ф5 (peer-session 2026-06-20-36-wp428-f5-agent-executors).
> Связанные: scenario-03-32 (/iwe single-shot), внешняя сессия /claude (external_session.py).

## Что делает

Команда `/agent <движок?> <текст>` открывает агентную сессию IWE через бота на выбранном
рантайме (executor). Раньше агентный канал был только Claude (`/claude`); теперь движок
выбирается явно.

```
/agent claude добавь фазу в WP-428
/agent kimi почисти импорты в handlers/iwe.py
/agent hermes как устроен онбординг?
/agent просто запрос           ← без движка → claude по умолчанию
```

## Движки

| Движок | Тип | Путь исполнения |
|--------|-----|-----------------|
| `claude` (по умолчанию) | агентный | SESSION-файл в GitHub → диспетчер на раннере → `claude -p` → commit |
| `kimi` | агентный | тот же путь, диспетчер запускает `kimi --print` |
| `hermes` | разговорный | напрямую `hermes_chat` (без диспетчера), tier ≥ T3 |

## Поток (claude / kimi)

1. Пилот: `/agent kimi <текст>`.
2. Бот валидирует движок, проверяет GitHub-доступ (creds), пишет `executor: kimi` в метаданные SESSION-файла.
3. Бот ставит FSM `ExternalSession.active`, показывает «Сессия открыта (движок: kimi)».
4. Диспетчер на раннере читает `executor` → запускает соответствующий рантайм → коммитит результат → отвечает в Telegram.
5. Продолжение хода — обычным текстом (как в `/claude`); `/close` завершает сессию.

## Поток (hermes)

1. Пилот: `/agent hermes <вопрос>`.
2. Бот проверяет tier (≥ T3, общий порог с префиксом «Гермес»). Ниже порога → подсказка использовать «Гермес, …».
3. Бот зовёт `hermes_chat` напрямую, отвечает одним сообщением. SESSION-файл и диспетчер не задействованы.

## Границы и тиры

- Тир-проверка на этой фазе — заглушка для пилота (T4 = все движки); hermes использует свой порог.
- Полный domain-scope (Парламент-модель) и approve-before-commit для scoped-тира — спин-офф WP-4XX.
- Активная сессия одна: `/agent` при активной сессии просит продолжить текстом или `/close`.

## Связанный код

- `handlers/external_session.py`: `cmd_agent`, `_parse_agent_args`, `_meta_content` (поле `executor`), `_create_session`, `_open_new_session`.
- Диспетчер (репо стратегии): `iwe-agent-dispatcher.py` — фабрика `Executor` (claude, kimi).
