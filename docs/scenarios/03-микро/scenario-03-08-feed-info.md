## 1. Триггер и маршрут

- Пользователь вводит `/feed_info` → `cmd_feed_info`
- Inline-переход из `/about` / features — `edit=True`

## 2. Содержимое

**Текст:** i18n `t('info.feed_*')` — описание Ленты: как устроена, темы недели, фиксации.

**Кнопки (tier-aware):**

| Tier / состояние | Кнопки |
|------------------|--------|
| T0 / T1 (нет подписки) | `[Купить подписку]` `[⚙️ Настройки]` |
| T2+ `feed_status='not_started'` | `[📖 Запустить Ленту]` `[⚙️ Настройки]` |
| T2+ `feed_status='active'` | `[📖 Получить дайджест]` `[⚙️ Настройки]` |
