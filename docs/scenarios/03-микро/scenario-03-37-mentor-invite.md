# 03.37 `/mentor_invite` — личное приглашение к согласию

> Наставник отвечает этой командой на сообщение участника в группе потока —
> бот сам пишет участнику в личку тот же запрос согласия, что у
> `/mentor_consent`. Решение пилота 17.09 (способ 2 из 3, способ 1 —
> периодическое сообщение в группе, способ 3 — встроить в онбординг — не
> делаем сейчас). Разбор: `docs/processes/process-19-mentorship-archive-tap.md`
> §«Обнаружение согласия».

## 1. Команда

```
Наставник (в группе потока, ответом на сообщение участника): /mentor_invite
```

Бот отправляет участнику **личное** сообщение с тем же текстом и кнопкой,
что `/mentor_consent`. Наставнику приходит подтверждение в группе.

### Ответы бота

- Нет reply-цели: «Ответь этой командой на сообщение участника, которому шлём приглашение.»
- Приглашение самого себя: «Нельзя пригласить самого себя.»
- Аккаунт наставника не привязан: «Не нашёл твой аккаунт платформы — сначала привяжи его (/link).»
- Группа не зарегистрирована за потоком: «Эта группа не зарегистрирована за потоком — сначала /mentor_stream.»
- Вызывающий не читатель потока: «Ты не числишься наставником или пилотом потока S1.»
- У участника нет аккаунта платформы: «У участника нет привязанного аккаунта платформы — приглашение недоступно.»
- Успех: «Приглашение отправлено участнику <имя> в личку.»
- Участник ни разу не писал боту (`TelegramForbiddenError` — Telegram не даёт
  боту заговорить первым): «Не получилось написать <имя> — участник ещё ни
  разу не писал боту в личку, Телеграм не разрешает боту заговорить первым.
  Попроси его прислать боту любое сообщение, потом повтори приглашение.»

## 2. Известные ограничения

- Резолв цели — только через `reply_to_message.from_user`. Упоминание по
  `@username` без reply не поддерживается (тот же выбор, что у остальной
  переписки — Ф2, `text_mention`-only).
- Согласие после успешной отправки — отдельное действие участника (тап по
  кнопке), эта команда только доставляет запрос, не записывает согласие
  сама (запись — общий `cb_mentor_consent`, тот же путь, что у
  `/mentor_consent`).
