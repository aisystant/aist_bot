# 03.01 Сценарий просмотра прогресса

> Описание команды /progress для просмотра статистики.

---

## Обзор

| Параметр | Значение |
|----------|----------|
| Команда | `/progress` |
| Тип | Сводка: Статистика |
| Варианты | Недельный отчёт, Полный отчёт |

---

## 1. Недельный отчёт (/progress)

### Сообщение бота

```
📊 *Прогресс за неделю: Иван*

📈 Активных дней за неделю (Марафон+Лента): 5
🏆 Баллы: 320

🏃 *Марафон*
День 7/14
📖 Уроков: 3. 📝 Заданий: 2

📚 *Лента*
Дайджестов: 3. Фиксаций: 2
Темы: История, Психология

[📚 Продолжить обучение]  ← главная кнопка (или [📖 Получить дайджест] для Ленты)
[📊 Полный отчёт] [⚙️ Настройки]
```

> **Примечание:** Детализация «По дням» отображается только в полном отчёте. Уроки и Задания — за текущую неделю (с понедельника).

### Иконки статусов дней (в полном отчёте)

| Иконка | Формат | Значение |
|--------|--------|----------|
| ✅ | День N: Урок: 1 \| Задание: 1 \| РП: 1 | День завершён |
| 🔄 | День N: Урок: 1 \| Задание: 0 \| РП: 0 | День в процессе |
| 📍 | День N: Урок: 0 \| Задание: 0 \| РП: 0 | День доступен |
| 🔒 | — | День заблокирован (не отображается) |

> **Формат:** `День N: Урок: X | Задание: Y | РП: Z`
> - **Урок** — количество пройденных уроков (theory)
> - **Задание** — количество пройденных заданий (practice)
> - **РП** — рабочие продукты
> - Дни отображаются в обратном порядке (сначала последний)

### Данные из БД

| Метрика | Источник | Период |
|---------|----------|--------|
| Активные дни (М+Л) | `activity_log` | С понедельника текущей недели |
| **Баллы** | `rewards.point_balances` (Neon, проекция WP-253 Ф9.3) | Текущий баланс |
| Уроков | `answers` (theory_answer) | С понедельника текущей недели |
| Заданий | `answers` (work_product) | С понедельника текущей недели |
| Дайджесты | `feed_sessions` (status='completed') | С понедельника текущей недели |
| Фиксации | `answers` (fixation) | С понедельника текущей недели |

## 2. Полный отчёт (кнопка)

### Callback

`progress_full`

### Сообщение бота

```
📊 *Полный отчёт с 15.01.2026: Иван*

📈 Активных дней (Марафон+Лента): 10 из 38

🏃 *Марафон*
День 7 из 14
📖 Уроков: 7/14
📝 Заданий: 6/14
Рабочих продуктов: 6

📋 *По дням:*
   ✅ День 7: Урок: 1 | Задание: 1 | РП: 1
   ✅ День 6: Урок: 1 | Задание: 1 | РП: 1
   ✅ День 5: Урок: 1 | Задание: 1 | РП: 1
   ✅ День 4: Урок: 1 | Задание: 1 | РП: 1
   ✅ День 3: Урок: 1 | Задание: 1 | РП: 1
   🔄 День 2: Урок: 1 | Задание: 0 | РП: 0
   ✅ День 1: Урок: 1 | Задание: 1 | РП: 1
Отставание: 1 дней

📚 *Лента*
Дайджестов: 8
Фиксаций: 5
Темы: История, Психология, Маркетинг

[📚 Продолжить обучение]
[« Назад]
```

### Данные из БД

| Метрика | Источник | Период |
|---------|----------|--------|
| Дата регистрации | `interns.created_at` | — |
| Дней с регистрации | Вычисляется: `today - created_at + 1` | — |
| Активные дни | `activity_log` | С начала |
| Рабочие продукты | `answers` | С начала |
| Дайджесты | `feed_sessions` | С начала |
| Фиксации | `answers` | С начала |
| **Отставание** | Вычисляется: `marathon_day - completed_days` | — |

### Расчёт отставания

**Формула:** `Отставание = День марафона − Завершённые дни`

- **День марафона** — календарный день с `marathon_start_date`
- **Завершённые дни** — количество дней, где все темы пройдены (статус ✅)

**Пример:**
- День марафона: 7
- Дни 1-3 завершены полностью (✅), дни 4-7 не завершены
- Отставание = 7 − 3 = **4 дня**

## 3. Различия отчётов

| Аспект | Недельный | Полный |
|--------|-----------|--------|
| Период | Пн текущей недели — сегодня | От регистрации |

| Кнопки | Полный отчёт, Настройки | Назад |

---

## 4. Диаграмма

```
/progress
    ↓
cmd_progress()
    ├─ get_activity_stats()           → activity_log (7 дней)
    ├─ get_weekly_marathon_stats()    → answers (неделя)
    ├─ get_weekly_feed_stats()        → feed_sessions (неделя)
    └─ get_work_products_by_day()     → answers (по дням)
    ↓
Недельный отчёт + [Полный отчёт] [Настройки]
    ↓
[Нажата "Полный отчёт"]
    ↓
show_full_progress()
    ↓
get_total_stats()                     → Все данные с начала
    ↓
Полный отчёт + [Назад]
```
