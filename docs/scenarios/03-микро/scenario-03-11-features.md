# 03.11 `/features`

> Каталог возможностей бота с per-user статусами: что доступно сейчас, что preview, что недоступно до апгрейда тира.

---

## Обзор

| Параметр | Значение |
|----------|----------|
| Команда | `/features` |
| Вид | Микро (C) |
| Файл | [`handlers/features.py:98`](../../../handlers/features.py) |
| Tier gate | Да — tier-aware display и кнопки |

---

## 1. Триггер и маршрут

- Пользователь вводит `/features` → `cmd_features`
- Handler вызывает `detect_ui_tier(chat_id)` → рендерит список фич с индикаторами доступности
- Кнопка действия зависит от тира (см. §3)

## 2. Содержимое

**Структура:** список фич сгруппирован по функциональным блокам. Каждая фича помечена:
- 🟢 **Доступна** — tier пользователя достаточен
- 🟡 **Preview** — можно попробовать, но с ограничениями (триал)
- 🔒 **Недоступна** — нужен апгрейд тира

**Текст:** i18n `features.*`.

## 3. Tier-aware кнопки

| Tier | Кнопка | Действие |
|------|--------|----------|
| **T0** | `[Привязать Aisystant]` | OAuth flow |
| **T1** | `[Оформить подписку]` | Купить «Бесконечное развитие» |
| **T2** | `[Подключить ЦД]` | Ory OAuth → T3 |
| **T3** | `[Подключить GitHub]` | GitHub OAuth → T4 |
| **T4** | — | Paywall не показывается |

**Правило:** текст paywall (§10 CLAUDE.md) НЕ ДОЛЖЕН обещать функциональность, отсутствующую у целевой команды. Урок: `/start` не показывает тир-инфо.
