# 03.41 Сценарий: заметки голосом через Siri (/siri)

> WP-384 / DP.SC.178. Команда айфона «Заметка в IWE»: Siri слушает мысль, текст уходит в бот по личному ключу и ложится туда же, куда заметки с точкой; Siri вслух говорит, куда записано.

---

## Обзор

| Параметр | Значение |
|----------|----------|
| Триггер | `/siri` в личном чате (ключ и шаги настройки); `/siri new` — заменить ключ |
| Приём заметок | `POST /api/notes`, заголовок `X-IWE-Api-Key`, тело `{"text": "..."}` |
| Результат | Строка в `fleeting-notes.md` репозитория заметок; ответ `{"ok", "say", "url"}`, `say` произносит Siri |
| Файлы логики | `handlers/siri.py`, `oauth_server.py::notes_shortcut_handler`, `core/fleeting_notes.py`, `db/queries/iwe_extension.py` |
| Обещание | DP.SC.178 |

---

## Предусловия

1. Пользователь привязал аккаунт Aisystant (`/link`).
2. Для записи — те же условия, что у «.текст»: доступ к заметкам, подключённый GitHub, выбранный репозиторий.

---

## Поток

1. **/siri.** Бот выдаёт личный ключ только для заметок (служба `iwe_notes_shortcut`, область `notes`; ключ браузерного расширения из `/iwe` здесь не подходит) и пошаговую настройку команды айфона: «Продиктовать текст» → «Получить содержимое URL» (POST, заголовок ключа, JSON с полем `text`) → «Получить значение из словаря» (`say`) → «Произнести текст». Повторный `/siri` показывает тот же ключ; `/siri new` выдаёт новый, старый перестаёт работать. Ключ хранится зашифрованным и не пишется в журнал.
2. **«Привет, Siri, Заметка в IWE».** Айфон сам распознаёт речь (звук в бот не уходит) и отправляет текст.
3. **Приём.** Бот проверяет ключ, частоту (не чаще раза в 5 сек на ключ), длину (до 4000 знаков), находит чат владельца и сохраняет заметку теми же проверками, что «.текст» (`core/fleeting_notes.save_fleeting_note`). Текст заметки в журнал не пишется.
4. **Ответ Siri.** «Записано в быстрые заметки, репозиторий <имя>.» или причина отказа. В Telegram бот отдельно не пишет: сообщения по своей инициативе идут только через центр уведомлений.

---

## Режим отказа

| Ситуация | Код | Что говорит Siri |
|----------|-----|------------------|
| Нет ключа или ключ не подошёл | 401 | «Ключ не подошёл. Получите новый в боте командой сири.» |
| Чаще раза в 5 сек | 429 | «Слишком часто. Подождите несколько секунд.» |
| Пустой текст или не JSON | 400 | «Не расслышал заметку. Повторите.» / «Не понял запрос.» |
| Длиннее 4000 знаков | 413 | «Заметка слишком длинная. Разбейте на части.» |
| Аккаунт не связан с ботом | 404 | «Аккаунт не привязан к боту.» |
| Нет доступа, GitHub, репозитория, нужен повторный вход, сбой записи | 200, `ok: false` | Причина и что сделать в боте |

---

## Не входит

- Вопросы к Наставнику через Siri (только заметки).
- Сообщение в чат о записи от Siri.
- Готовый файл команды для установки одной кнопкой (пока настройка вручную по шагам из `/siri`).
