# 01.02 Сценарий Ленты

> Полное описание процесса гибкого обучения по дайджестам с точки зрения потока сообщений, данных и прогресса.

---

## Обзор

| Параметр | Значение |
|----------|----------|
| Структура | Недели с произвольной длительностью |
| Тем в неделю | 1-3 (выбирает Читатель) |
| Дайджестов в день | 1 |
| Глубина | Увеличивается с каждым дайджестом |
| Участник | Читатель |

## 1. Запуск Ленты

### Точки входа

| Команда | Когда используется |
|---------|-------------------|
| `/feed` | Прямой запуск Ленты |
| `/mode` | Переключение режима |

### Начало новой недели

```
Читатель → /feed

Бот → Служебное: Подтверждение
      "Генерирую темы..."

Бот → Запрос: Меню тем
      "Выберите до 3 тем на эту неделю:"

      "1️⃣ Тема A — {почему актуальна}"
      "2️⃣ Тема B — {почему актуальна}"
      "3️⃣ Тема C — {почему актуальна}"
      "4️⃣ Тема D — {почему актуальна}"
      "5️⃣ Тема E — {почему актуальна}"

      [☐ Тема A] [☐ Тема B] [☐ Тема C]
      [☐ Тема D] [☐ Тема E]
      [✅ Подтвердить выбор]
```

### Выбор тем

Читатель может выбрать темы двумя способами:

**Способ 1: Кнопки**
- Нажимает кнопки тем (☐ → ☑)
- Максимум 3 темы
- Нажимает "✅ Подтвердить"

**Способ 2: Текст**
- Пишет: `1, 3` или `тема 2 и собранность`
- Поддерживает кастомные темы: `хочу про внимание`

```
Читатель → "1, 3" или нажимает кнопки

Бот → Служебное: Подтверждение
      "✅ Темы выбраны: Тема A, Тема C"

      [📖 Получить дайджест] [⏰ По расписанию]
```

### Сохраняемые данные

**Таблица `feed_weeks`:**
```sql
INSERT INTO feed_weeks (
    chat_id, week_number, week_start,
    suggested_topics, accepted_topics,
    current_day, status
) VALUES (
    123456, 1, '2026-01-20',
    '["Тема A", "Тема B", ...]',
    '["Тема A", "Тема C"]',
    1, 'active'
)
```

## 2. Структура недели

### Модель глубины (depth_level)

В Ленте `current_day` — это **уровень глубины**, а не день недели:

| current_day | Глубина | Что содержит дайджест |
|-------------|---------|----------------------|
| 1 | Базовый | Введение в все выбранные темы |
| 2 | Практический | Примеры применения |
| 3 | Интеграция | Связи между темами |
| 4+ | Глубокий | Детальный анализ |

### Все темы — одновременно

Если Читатель выбрал 3 темы, каждый дайджест содержит **все 3 темы** на текущем уровне глубины.

```
Неделя с темами: [Внимание, Собранность, Рефлексия]

День 1 (depth=1): Базовое введение в все 3 темы
День 2 (depth=2): Практические примеры для всех 3 тем
День 3 (depth=3): Как темы связаны между собой
...
```

## 3. Полная последовательность дня

### Диаграмма потока

```
[Читатель]                            [Бот]

/feed или "Получить дайджест" ──────► Проверка: есть ли активная неделя?
                                      ↓
                                      [Если нет сессии на сегодня]
                                      Служебное: Подтверждение
                                      "Генерирую контент..."
                                      ↓
                                      Материал: Дайджест
                                      "📖 Дайджест: {темы}"
                                      "Углубление {N}"
                                      [основной текст по всем темам]

                                      Вопрос дайджеста
                                      "💭 {вопрос для размышления}"

                                      [✍️ Написать фиксацию]
                                      [❓ Задать вопрос]
                                      [📋 Темы недели]

[Вариант А: Фиксация] ──────────────► FSM: waiting_fixation

Фиксация (≥10 симв.) ───────────────► Служебное: Подтверждение
                                      "✅ Фиксация сохранена!"

                                      Сводка: Статистика
                                      "📊 Активных дней: X"
                                      "🔥 Текущая серия: Y"

[Вариант Б: Вопрос] ────────────────► FSM: reading_content

Вопрос пользователя ────────────────► Обратная связь: Консультация
                                      "{ответ с источниками}"

[Вариант В: Темы недели] ───────────► Меню редактирования тем
```

## 4. Все типы сообщений

### От бота к Читателю

| Тип | Подтип | Когда отправляется | Пример |
|-----|--------|-------------------|--------|
| **Материал** | Дайджест | При запросе `/feed` | Текст по выбранным темам |
| **Вопрос** | Вопрос дайджеста | В конце дайджеста | "Как это связано с вашей работой?" |
| **Обратная связь** | Консультация | На вопрос пользователя | Ответ через MCP |
| **Запрос** | Меню тем | В начале новой недели | Список из 5 предложенных тем |
| **Сводка** | Статистика | После фиксации | Активные дни, серия |
| **Служебное** | Подтверждение | На каждое действие | "✅ Принято", "Генерирую..." |

### От Читателя к боту

| Тип | FSM-состояние | Валидация | Пример |
|-----|---------------|-----------|--------|
| **Выбор тем** | `choosing_topics` | 1-3 темы | "1, 3" или кнопки |
| **Фиксация** | `waiting_fixation` | ≥10 символов | "Главное, что понял..." |
| **Вопрос пользователя** | `reading_content` | ≥3 символа | "А как это применить?" |
| **Редактирование тем** | `editing_topic` | 1-3 темы | "1, 2, Внимание" |

### Вопрос в Ленте (РП-498 Ф17)

Свободный текст ≥3 символов (без `?`) в состоянии `feed.digest` уходит в консультацию, как и текст с `?`:

| Что | Как |
|-----|-----|
| Куда | `go_to("common.consultation")` с `question` и `context_topic` (темы недели через запятую); после ответа пользователь остаётся в консультации (следующий текст продолжает диалог, окно 15 минут); в Ленту возвращает кнопка «↩️ Завершить» или любая кнопка Ленты под дайджестом |
| Память диалога | та же, что у консультации: до 5 пар «вопрос-ответ» (см. `scenario-02-04-consultation.md`, раздел 12). Реплика вроде «опиши» после ответа с встречным вопросом получает контекст |
| Что видит Читатель | индикатор «Думаю...», роли («🧭 Подключаю Навигатора…»), кнопки под ответом 👍 / 🔍 / ✏️ / ↩️; ответ идёт через поиск с инструментами, задержка выше прежней |
| Подписка | проверка доступа к консультации (бесплатные роли освобождены); при истёкшей подписке вместо ответа показывается экран оплаты |
| Фиксация | не затронута: пока ждём фиксацию (`waiting_fixation`), текст сохраняется как фиксация, не как вопрос |
| Откат | переменная окружения `FEED_QUESTIONS_VIA_CONSULTATION=false` возвращает прежний одноразовый ответ Ленты без памяти. Тот же путь используется, когда State Machine не поднята |
| Журнал вопросов | `qa_history.context_topic` = темы недели, как раньше; ответы получают кнопки, поэтому у них появляется отметка `helpful` |

## 5. Сохраняемые данные

### При создании дайджеста

**Таблица `feed_sessions`:**
```sql
INSERT INTO feed_sessions (
    week_id, day_number, topic_title,
    content, session_date, status
) VALUES (
    1, 2, 'Внимание, Собранность',
    '{"intro": "...", "main_content": "...", "reflection_prompt": "..."}',
    '2026-01-22', 'active'
)
```

### При фиксации

**Таблица `feed_sessions` (обновление):**
```sql
UPDATE feed_sessions SET
    fixation_text = 'Текст фиксации...',
    status = 'completed',
    completed_at = NOW()
WHERE id = 1
```

**Таблица `feed_weeks` (обновление):**
```sql
UPDATE feed_weeks SET
    current_day = current_day + 1
WHERE id = 1
```

**Таблица `activity_log`:**
```sql
INSERT INTO activity_log (
    chat_id, activity_date, activity_type, mode, reference_id
) VALUES (
    123456, '2026-01-22', 'feed_fixation', 'feed', 1
)
```

**Таблица `interns` (обновление):**
```sql
UPDATE interns SET
    active_days_total = active_days_total + 1,
    active_days_streak = ...,
    last_active_date = '2026-01-22'
WHERE chat_id = 123456
```

## 6. Схема данных

### Таблица `feed_weeks`

| Поле | Тип | Описание |
|------|-----|----------|
| `id` | SERIAL | Первичный ключ |
| `chat_id` | BIGINT | ID пользователя |
| `week_number` | INTEGER | Номер недели (1, 2, 3...) |
| `week_start` | DATE | Понедельник недели |
| `suggested_topics` | JSON | Предложенные темы (5 шт) |
| `accepted_topics` | JSON | Выбранные темы (1-3 шт) |
| `current_day` | INTEGER | Уровень глубины |
| `status` | TEXT | planning / active / completed |
| `ended_at` | TIMESTAMP | Дата завершения |

### Таблица `feed_sessions`

| Поле | Тип | Описание |
|------|-----|----------|
| `id` | SERIAL | Первичный ключ |
| `week_id` | INTEGER | Ссылка на feed_week |
| `day_number` | INTEGER | Уровень глубины (= current_day) |
| `topic_title` | TEXT | Все темы через запятую |
| `content` | JSON | Сгенерированный контент |
| `session_date` | DATE | Дата дайджеста |
| `status` | TEXT | active / completed |
| `fixation_text` | TEXT | Текст фиксации |
| `completed_at` | TIMESTAMP | Дата завершения |

### Структура `content` (JSON)

```json
{
    "intro": "Вводное предложение...",
    "main_content": "Основной текст по всем темам...",
    "topics_list": ["Тема A", "Тема C"],
    "reflection_prompt": "Вопрос для размышления...",
    "depth_level": 2
}
```

## 8. Цикл недели

### Жизненный цикл

```
┌─────────────────────────────────────────────────────────────┐
│  НАЧАЛО НЕДЕЛИ                                              │
│                                                             │
│  /feed → Генерация 5 тем                                    │
│       → feed_week создана (status = PLANNING)               │
│       → Читатель выбирает 1-3 темы                          │
│       → feed_week (status = ACTIVE, current_day = 1)        │
└─────────────────────────────────────────────────────────────┘
                              ↓
┌─────────────────────────────────────────────────────────────┐
│  ДЕНЬ N (повторяется)                                       │
│                                                             │
│  /feed → Проверка: есть сессия на сегодня?                  │
│       → Нет: создаём feed_session (depth = current_day)     │
│       → Генерируем дайджест через Claude                    │
│       → Показываем дайджест + вопрос                        │
│                                                             │
│  Фиксация → feed_session.status = completed                 │
│          → feed_week.current_day += 1                       │
│          → activity_log (feed_fixation)                     │
└─────────────────────────────────────────────────────────────┘
                              ↓
┌─────────────────────────────────────────────────────────────┐
│  ЗАВЕРШЕНИЕ / НОВАЯ НЕДЕЛЯ                                  │
│                                                             │
│  Читатель → "Новая неделя" или /feed                        │
│          → feed_week (status = COMPLETED)                   │
│          → Новая неделя (week_number += 1)                  │
└─────────────────────────────────────────────────────────────┘
```

### Особенности

1. **Неделя не завершается автоматически** — Читатель может углубляться в темы неограниченно
2. **Переход на новую неделю** — по желанию Читателя через кнопку или `/feed`
3. **Темы можно менять** — через меню "📋 Темы недели"

## 9. Особые состояния

### Нет активной недели

```
Читатель → /feed (нет активной недели)

Бот → Запрос: Меню тем
      [Генерация и показ 5 тем]
```

### Неделя в планировании

```
Читатель → "Получить дайджест" (темы не выбраны)

Бот → Служебное: Ошибка
      "Сначала выберите темы"
```

### Незавершённая вчерашняя сессия

```
Читатель → /feed (есть сессия без фиксации)

Бот → Материал: Дайджест
      [Показывает вчерашний дайджест]
      "Напишите фиксацию, чтобы продолжить"
```

### Дайджест уже завершён сегодня

```
Читатель → /feed (уже есть фиксация за сегодня)

Бот → Служебное: Подтверждение
      "✅ Дайджест на сегодня завершён"
      "Возвращайтесь завтра или начните новую неделю"
```
