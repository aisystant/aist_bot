# 02.22 Сценарий голосового ввода

> WP-384 / DP.SC.178 «Голосовой канал IWE (ввод)».
> Голосовое сообщение в боте → расшифровка → тот же путь, что у набранного текста: по умолчанию заметка как «.текст», вопрос Наставнику — если голосовое начинается со слова «вопрос».

---

## Обзор

| Параметр | Значение |
|----------|----------|
| Триггер | Голосовое сообщение в личном чате с ботом |
| Результат | Эхо расшифровки; заметка в `fleeting-notes.md` репозитория заметок (как «.текст») или ответ Наставника (как «?текст») |
| Файл логики | `handlers/voice.py` |
| Обещание | DP.SC.178 |

---

## Предусловия

1. Пользователь привязал аккаунт Aisystant (T1+).
2. Дано согласие `voice_processing` (кнопка при первом голосовом).
3. В окружении бота задан `STT_API_KEY` (по умолчанию провайдер OpenRouter, модель `openai/gpt-4o-mini-transcribe`; меняются переменными `STT_BASE_URL`, `STT_MODEL`).
4. Для заметки — те же условия, что у «.текст»: доступ к заметкам, подключённый GitHub и выбранный репозиторий (`handlers/github.py::handle_fleeting_note`).

---

## Поток

1. **Голосовое.** Длительность не больше `VOICE_MAX_DURATION_SEC` (по умолчанию 60 сек); длиннее — отказ с предложением разбить или написать текстом.
2. **Согласие (первый раз).** Бот объясняет: запись распознаёт сервис OpenAI через OpenRouter, запись не хранится, текст сохраняется заметкой туда же, куда заметки с точки, а голосовое со слова «вопрос» уходит Наставнику. Кнопка «✅ Согласиться» (callback `voice_consent_grant`).
3. **Распознавание.** Бот скачивает OGG в память и отправляет в `/audio/transcriptions` провайдера; запись не пишется на диск, расшифровка не пишется в журнал.
4. **Эхо.** «🎤 <расшифровка>».
5. **Заметка (по умолчанию).** Расшифровка передаётся обработчику заметок как «.<расшифровка>»: доступ, GitHub, репозиторий проверяются там же, ответ «Записано → ссылка». Если голосовое было ответом на сообщение, оно склеивается с ним, как у текстовой заметки.
6. **Вопрос («вопрос …»).** Слово «вопрос» в начале отрезается, остаток уходит в машину состояний как «?<вопрос>» (глобальное событие `consultation`, отвечает Наставник). Пользователь без завершённого онбординга получает просьбу задать вопрос текстом.

---

## Режим отказа

| Ситуация | Реакция |
|----------|---------|
| Нет аккаунта | Подсказка подключить аккаунт |
| Нет согласия | Кнопка согласия |
| Не задан `STT_API_KEY` | «Голосовые временно недоступны» |
| Не скачалось голосовое | «Не удалось получить голосовое» |
| Ошибка распознавания | «Не смог распознать, повтори или напиши текстом» |
| Пустая расшифровка | «Скажи ещё раз или напиши текстом» |
| Нет доступа к заметкам, GitHub или репозитория | Те же сообщения, что у «.текст» |
| Вопрос не построен | «Задай его текстом, начав с «?»» |

---

## Не входит

- Голосовые ответы (озвучка).
- Живой голосовой разговор.
- Записи длиннее 60 сек.
- Голосовые в группах и каналах.
