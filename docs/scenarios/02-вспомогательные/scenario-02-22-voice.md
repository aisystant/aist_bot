# 02.22 Сценарий голосового ввода

> WP-384 / DP.SC.178 «Голосовой канал IWE (ввод)».
> Голосовое сообщение в боте → расшифровка → заметка в личном руководстве (если подключено) → тот же ответ, что на вопрос текстом с «?».

---

## Обзор

| Параметр | Значение |
|----------|----------|
| Триггер | Голосовое сообщение в личном чате с ботом |
| Результат | Эхо расшифровки; заметка `history/YYYY-MM-DD-voice-HHMMSS.md` в личном руководстве (если подключено); ответ Наставника |
| Файл логики | `handlers/voice.py` |
| Обещание | DP.SC.178 |

---

## Предусловия

1. Пользователь привязал аккаунт Aisystant (T1+).
2. Дано согласие `voice_processing` (кнопка при первом голосовом).
3. В окружении бота задан `STT_API_KEY` (по умолчанию провайдер OpenRouter, модель `openai/gpt-4o-mini-transcribe`; меняются переменными `STT_BASE_URL`, `STT_MODEL`).
4. Для заметки — установлено приложение «Aisystant Personal Guide» (без него бот отвечает, но заметку не сохраняет).

---

## Поток

1. **Голосовое.** Длительность не больше `VOICE_MAX_DURATION_SEC` (по умолчанию 60 сек); длиннее — отказ с предложением разбить или написать текстом.
2. **Согласие (первый раз).** Бот объясняет: запись распознаёт сервис OpenAI через OpenRouter, запись не хранится, расшифровка сохраняется заметкой, на вопрос отвечает Наставник. Кнопка «✅ Согласиться» (callback `voice_consent_grant`).
3. **Распознавание.** Бот скачивает OGG в память и отправляет в `/audio/transcriptions` провайдера; запись не пишется на диск, расшифровка не пишется в журнал.
4. **Эхо и заметка.** Одним сообщением: расшифровка и строка «Записал заметкой в личное руководство» или «Заметку не сохранил: личное руководство не подключено».
5. **Ответ.** Расшифровка уходит в машину состояний как текст «?<расшифровка>», то есть тем же путём, что вопрос, набранный с «?» (глобальное событие `consultation`, отвечает Наставник). Пользователь без завершённого онбординга получает просьбу задать вопрос текстом.

---

## Режим отказа

| Ситуация | Реакция |
|----------|---------|
| Нет аккаунта | Подсказка подключить аккаунт |
| Нет согласия | Кнопка согласия |
| Не задан `STT_API_KEY` | «Голосовые временно недоступны» |
| Не скачалось голосовое | «Не удалось получить голосовое» |
| Ошибка распознавания | «Не смог распознать, повтори или напиши текстом» |
| Пустая расшифровка | «Скажи ещё раз или напиши текстом» |
| Нет личного руководства | Эхо без заметки, ответ приходит |
| Ответ не построен | «Задай вопрос текстом, начав с «?»» |

---

## Не входит

- Голосовые ответы (озвучка).
- Живой голосовой разговор.
- Записи длиннее 60 сек.
- Голосовые в группах и каналах.
