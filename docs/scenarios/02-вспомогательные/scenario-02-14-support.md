# Сценарий 02-14: /support — Обращение в службу поддержки

> **Вид:** B (FSM, несколько экранов)  
> **SC:** DP.SC.150  
> **WP:** WP-341

## Описание

Пользователь создаёт тикет поддержки через Chatwoot API Channel. Ответы агента приходят обратно в Telegram.

## Условия входа

- Пользователь прошёл онбординг (`is_onboarded = true`)
- `CHATWOOT_URL` задан в env

## FSM-состояния

```
/support
  └─► SupportState.topic     — выбор темы (inline keyboard)
        └─► SupportState.description — ввод текста (≥5 символов)
              └─► SupportState.priority — выбор приоритета (inline keyboard)
                    └─► [создание тикета в Chatwoot] → подтверждение
```

## Клавиатуры

**Тема (2×2):**
| 🐛 Баг | ❓ Вопрос |
|--------|---------|
| 💡 Пожелание | 📋 Прочее |

**Приоритет (1×2):**
| 🚨 Срочно | 🔵 Обычный |

## Поток (happy path)

1. Пользователь → `/support`
2. Бот → «Выберите тему» + inline keyboard
3. Пользователь → тап на тему
4. Бот → «Опишите проблему или вопрос:»
5. Пользователь → текст описания
6. Бот → «Приоритет:» + inline keyboard
7. Пользователь → тап на приоритет
8. Бот → «⏳ Создаю тикет…»
9. Бот → создаёт contact + conversation в Chatwoot (Public API)
10. Бот → «✅ Тикет #N создан. Агент ответит в течение 24 часов.»
11. Агент отвечает в Chatwoot UI → Chatwoot шлёт webhook → бот пересылает в TG: «🛟 Агент поддержки: {текст}»

## Режим отказа

| Ситуация | Поведение |
|----------|-----------|
| `CHATWOOT_URL` не задан | «Служба поддержки временно недоступна. Напишите @aisystant напрямую.» |
| Chatwoot API недоступен (контакт) | «Не удалось создать контакт. Попробуйте позже.» |
| Chatwoot API недоступен (диалог) | «Не удалось открыть тикет. Попробуйте позже.» |
| Описание < 5 символов | «Пожалуйста, опишите подробнее (минимум 5 символов).» |

## Пример реальной сессии (2026-05-20)

```
Пользователь: /support
Бот: 🛟 Служба поддержки — выбор темы [🐛 Баг | ❓ Вопрос | 💡 Пожелание | 📋 Прочее]
Пользователь: тап 🐛 Баг
Бот: Тема: 🐛 Баг — Опишите проблему или вопрос:
Пользователь: тест-3 проблемы
Бот: Приоритет: [🚨 Срочно | 🔵 Обычный]
Пользователь: тап 🚨 Срочно
Бот: ✅ Тикет #4 создан. Тема: 🐛 Баг · 🚨 Срочно. Агент ответит в этом чате.
-- через 3 минуты --
Бот: 🛟 Агент поддержки: Все пришло
```
