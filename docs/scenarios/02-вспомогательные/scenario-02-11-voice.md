# 02.11 Сценарий голосового ввода

> WP-384 Ф2 / DP.SC.178 «Голосовой канал IWE (Talk Mode — ввод)».
> Голосовое сообщение в боте → текст → заметка в personal-guide + best-effort ответ.

---

## Обзор

| Параметр | Значение |
|----------|----------|
| Триггер | Голосовое сообщение в личном чате с ботом |
| Результат | Сохранённая расшифровка в `history/YYYY-MM-DD-voice-HHMMSS.md` и текстовый ответ |
| Файл логики | `handlers/voice.py` |
| Service Clause | DP.SC.178 |

---

## Предусловия

1. Пользователь привязал Ory-аккаунт (T1+).
2. Дано согласие `voice_processing` (inline-кнопка при первом голосовом).
3. Установлен GitHub App «Aisystant Personal Guide» и создано репо `personal-guide`.
4. `OPENAI_API_KEY` настроен в окружении бота.

---

## Поток

### 1. Пользователь отправляет голосовое сообщение

- Аудио ≤ `VOICE_MAX_DURATION_SEC` (по умолчанию 60 сек).
- Длиннее → отказ с предложением разбить или написать текстом.

### 2. Согласие (только при первом использовании)

Бот показывает:

- Куда уходит аудио: OpenAI Whisper.
- Что сохраняется: только расшифровка, аудио удаляется.
- Inline-кнопка «✅ Согласиться» (callback `voice_consent_grant`).

### 3. Распознавание

- Бот скачивает OGG в память.
- `AsyncOpenAI.audio.transcriptions.create(model=WHISPER_MODEL)`.
- Аудио не пишется на диск и не хранится.

### 4. Сохранение заметки

- Расшифровка сохраняется в `history/YYYY-MM-DD-voice-HHMMSS.md`.
- Frontmatter помечает источник `voice` и тег `voice-log`.
- Если сохранение не удалось → пользователю сообщается об ошибке.

### 5. Best-effort ответ

- Расшифровка отправляется в `gateway_mcp.hermes_chat`.
- Пользователь получает:
  - Эхо расшифровки.
- Если Hermes недоступен → сообщение «Если нужно действие — уточни текстом».

---

## Режим отказа

| Ситуация | Реакция |
|----------|---------|
| Нет аккаунта | Подсказка подключить аккаунт |
| Нет согласия | Inline-кнопка согласия |
| Нет GitHub App | Подсказка подключить личное руководство |
| Ошибка Whisper | «Не смог распознать, повтори текстом» |
| Ошибка сохранения заметки | Предупреждение с просьбой проверить настройки |

---

## Out of scope (Ф2)

- TTS / голосовые ответы.
- Bidirectional voice.
- Chunking аудио > 60 сек.
- Автоопределение языка.
