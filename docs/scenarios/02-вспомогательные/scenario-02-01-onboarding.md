# 02.01 Сценарий онбординга

> Slim-онбординг: 4 шага (имя → длительность → расписание → старт).
> Профиль (occupation/interests/values/goals) — через /profile или /settings после онбординга.

---

## Обзор

| Параметр | Значение |
|----------|----------|
| Команда запуска | `/start` |
| Количество шагов | 4 + подтверждение |
| Результат | Готовый профиль Ученика (базовый) |
| Персонализация | Через /profile (отложенная) |

---

## 1. Определение языка (Шаг 0)

### Автоматическое определение

При `/start` бот определяет язык по `language_code` из Telegram:

| Код Telegram | Язык бота |
|--------------|-----------|
| `ru` | Русский |
| `en` | English |
| `es` | Español |
| `uk`, `be`, `kk` | Русский (близкие языки) |
| `pt` | Español (португальский → испанский) |
| Остальные | English (по умолчанию) |

### Двуязычное приветствие

Если язык неизвестен, бот отправляет приветствие на двух языках (EN + RU).

## 2. Полная последовательность шагов

### Диаграмма потока

```
[Пользователь]                        [Бот]

/start ─────────────────────────────► Определение языка
                                      ↓
                                      Welcome: правила Марафона,
                                      путь T1→T4, "Как тебя зовут?"
                                      FSM: waiting_for_name

Имя (текст) ────────────────────────► "Приятно познакомиться, {name}!"
                                      "Сколько минут на одну тему?"
                                      [⚡ 5 мин] [🕑 15 мин] [🕓 25 мин]
                                      FSM: waiting_for_study_duration

Кнопка длительности ────────────────► "Во сколько напоминать?"
                                      "Формат: ЧЧ:ММ (часовой пояс: Москва)"
                                      FSM: waiting_for_schedule

Время (ЧЧ:ММ) ──────────────────────► "Когда начнём марафон?"
                                      [🚀 Сегодня] [📅 Завтра] [📅 Послезавтра]
                                      FSM: waiting_for_start_date

Кнопка даты ────────────────────────► Сводка: Профиль
                                      "📋 Ваш профиль:"
                                      "{все данные}"
                                      [Да] [🔄]
                                      FSM: confirming_profile

"Да" ───────────────────────────────► Служебное: Подтверждение
                                      "🎉 Добро пожаловать в марафон!"
                                      [Начать сейчас] [По расписанию]
                                      FSM: cleared
```

## 3. Детали каждого шага

### Шаг 1: Имя

| Параметр | Значение |
|----------|----------|
| FSM состояние | `waiting_for_name` |
| Тип ввода | Текст |
| Валидация | `.strip()` |
| Сохраняется | `name`, `language` |

**Сообщение бота:**
```
Привет! Я помогу тебе стать систематическим учеником.
Как тебя зовут?
```

### Шаг 2: Занятие

| Параметр | Значение |
|----------|----------|
| FSM состояние | `waiting_for_occupation` |
| Тип ввода | Текст |
| Валидация | `.strip()` |
| Сохраняется | `occupation` |

**Сообщение бота:**
```
Приятно познакомиться, {name}!

Чем ты занимаешься?
_Например: разработчик, маркетолог, студент_
```

### Шаг 3: Интересы

| Параметр | Значение |
|----------|----------|
| FSM состояние | `waiting_for_interests` |
| Тип ввода | Текст (через `,` или `;`) |
| Валидация | Парсинг в массив |
| Сохраняется | `interests` (JSON) |

**Сообщение бота:**
```
Какие у тебя интересы и хобби?
_Через запятую: гольф, чтение, путешествия_
_Это поможет приводить близкие тебе примеры._
```

**Обработка:**
```python
interests = [i.strip() for i in text.replace(',', ';').split(';') if i.strip()]
# "гольф, чтение" → ["гольф", "чтение"]
```

### Шаг 4: Мотивация

| Параметр | Значение |
|----------|----------|
| FSM состояние | `waiting_for_motivation` |
| Тип ввода | Текст |
| Валидация | `.strip()` |
| Сохраняется | `motivation` |

**Сообщение бота:**
```
*Что для тебя по-настоящему важно в жизни?*
_Это поможет добавлять мотивационные блоки._
```

### Шаг 5: Цели

| Параметр | Значение |
|----------|----------|
| FSM состояние | `waiting_for_goals` |
| Тип ввода | Текст |
| Валидация | `.strip()` |
| Сохраняется | `goals` |

**Сообщение бота:**
```
*Что ты хочешь изменить в своей жизни?*
_Это поможет связать материал с твоими целями._
```

### Шаг 6: Длительность сессии

| Параметр | Значение |
|----------|----------|
| FSM состояние | `waiting_for_study_duration` |
| Тип ввода | Кнопки |
| Варианты | 5, 15, 25 минут |
| Сохраняется | `study_duration` |

**Сообщение бота:**
```
Сколько минут готов уделять одной теме?

[⚡ 5 минут] [🕑 15 минут] [🕓 25 минут]
```

**Варианты:**

| Кнопка | Callback | Описание |
|--------|----------|----------|
| ⚡ 5 минут | `duration_5` | Быстрый обзор (~500 слов) |
| 🕑 15 минут | `duration_15` | Стандартное изучение (~1500 слов) |
| 🕓 25 минут | `duration_25` | Полное погружение (~2500 слов) |

### Шаг 7: Расписание

| Параметр | Значение |
|----------|----------|
| FSM состояние | `waiting_for_schedule` |
| Тип ввода | Текст (ЧЧ:ММ) |
| Валидация | 0-23 часы, 0-59 минуты |
| Сохраняется | `schedule_time` |

**Сообщение бота:**
```
Во сколько напоминать о новой теме?

_Формат: ЧЧ:ММ (например 09:00). Часовой пояс: Москва (UTC+3)_
```

**Валидация:**
```python
try:
    h, m = map(int, text.strip().split(":"))
    if not (0 <= h <= 23 and 0 <= m <= 59):
        raise ValueError
    normalized = f"{h:02d}:{m:02d}"  # "9:5" → "09:05"
except:
    # Ошибка: "Попробуй ещё раз (ЧЧ:ММ)"
```

### Шаг 8: Дата старта

| Параметр | Значение |
|----------|----------|
| FSM состояние | `waiting_for_start_date` |
| Тип ввода | Кнопки |
| Варианты | Сегодня, Завтра, Послезавтра |
| Сохраняется | `marathon_start_date` |

**Сообщение бота:**

```
14-дневный марафон

[🚀 Сегодня]
[📅 Завтра (25.01)]
[📅 Послезавтра (26.01)]
```

**Варианты:**

| Кнопка | Callback | Дата |
|--------|----------|------|

| 📅 Послезавтра | `start_day_after` | `today + 2 дня` |

## 4. Подтверждение профиля

### Сообщение со сводкой

```
📋 *Ваш профиль:*

👤 *Имя:* {name}
💼 *Занятие:* {occupation}
🎨 *Интересы:* {interests_list}

💫 *Что важно:* {motivation}
🎯 *Что изменить:* {goals}

⚡ 5 минут на тему
⏰ Напоминание в 09:05
🗓 Старт марафона: *25.01.2025*

Всё верно?

[Да] [🔄]
```

### Кнопка "Да"

- Callback: `confirm`
- Действие: `onboarding_completed = TRUE`
- Переход: финальное приветствие

### Кнопка "🔄" (Редактировать)

- Callback: `restart`
- Действие: возврат к шагу 1
- Данные в БД **не удаляются**, перезаписываются

## 7. Особые случаи

### Возвращение после онбординга

Если `onboarding_completed = TRUE`:

```
Ученик → /start

Бот → "С возвращением, {name}!
      📊 {Режим} • {X} дн. активности • 🔥 {streak}

      /learn — получить тему
      /progress — мой прогресс
      /profile — мой профиль
      /update — обновить настройки
      /mode — выбрать режим"
```

**Строка прогресса:**
- `{Режим}` — "Марафон" или "Лента" (из `intern['mode']`)
- `{X} дн. активности` — `active_days_total`
- `🔥 {streak}` — показывается только если `active_days_streak > 1`

### Ошибка валидации расписания

```
Ученик → "25:70"

Бот → "Попробуй ещё раз (ЧЧ:ММ)"
      FSM остаётся в waiting_for_schedule
```

## 10. OAuth state через PostgreSQL (WP-212)

Онбординг включает OAuth-шаги для интеграций: Aisystant (LMS), Ory (ЦД), GitHub (заметки/публикации), Google Calendar, Linear, Wakatime.

### 10.1. Проблема in-memory state

Раньше OAuth `state` (UUID для защиты от CSRF) хранился в памяти бота. При redeploy Railway — instance перезапускается, memory очищается, callback с редиректа приходит на новый instance → `state` не найден → OAuth падает.

### 10.2. Решение: `oauth_pending_states` таблица

| Поле | Тип | Описание |
|------|-----|----------|
| `state` | TEXT | PK, random UUID |
| `provider` | TEXT | `github` / `ory` / `google_calendar` / `linear` / `wakatime` / `discourse` |
| `telegram_user_id` | BIGINT | ID пользователя |
| `created_at` | TIMESTAMP | Для cleanup (TTL 15 мин рекомендуется) |

См. [tables.md §4.3](../../data/tables.md).

### 10.3. Flow

```
1. cmd_<provider> → generate UUID state
2. oauth_pending_states INSERT (state, provider, telegram_user_id)
3. Отправка redirect URL с ?state=<uuid>
4. User в браузере проходит consent
5. Callback приходит на /oauth/callback/{provider}?state=<uuid>
6. handlers/oauth_callback.py читает oauth_pending_states WHERE state=<uuid>
7. Получает telegram_user_id → сохраняет tokens в *_connections таблицу
8. oauth_pending_states DELETE (или TTL cleanup)
```

### 10.4. Cleanup

Индекс `idx_oauth_states_created` поддерживает cleanup устаревших states. TTL логика — в scheduler (старше 15 минут → DELETE).

### 10.5. Правило

Любой новый OAuth-провайдер должен:
1. Использовать `oauth_pending_states` (НЕ in-memory dict)
2. Указать свой `provider` literal в INSERT
3. Обработать callback в `handlers/oauth_callback.py`
4. Сохранить токены в свою `*_connections` таблицу

## 11. Экраны A/B — новый поток /start для новых пользователей (WP-349)

> **Заменяет** прежний welcome-текст + nav_buttons в блоке «возвращение / новый пользователь».

После определения языка и сохранения имени `/start` разветвляется на два экрана:

### Экран A — аккаунт НЕ привязан (`_try_auto_link()` → False)

```
Привет, {name}! 👋

Добро пожаловать в Мастерскую инженеров-менеджеров.
...
Для начала свяжите аккаунт Aisystant — это позволит
платформе отслеживать прогресс и персонализировать обучение.

[🔗 Связать аккаунт Aisystant]   ← callback: onboarding_link_start
```

**callback `onboarding_link_start`:**
1. `answer()` + `edit_reply_markup(None)` (double-tap protection)
2. Если уже привязан → `show_consent_optin()`
3. Если найден по tg_id (`_aisystant.find_user_by_tg`) → авто-сохранение → `show_consent_optin()`
4. Если не найден → кнопки `[🔗 Войти в Aisystant (URL)] + [✅ Проверить (link_check)]`

### Экран B — аккаунт привязан (`_try_auto_link()` → True)

```
Привет, {name}! 👋

...✅ Аккаунт привязан!
Следующий шаг — согласие на трекинг развития.

[consent screen следует немедленно]
```

После экрана B сразу вызывается `show_consent_optin()`.

### Возвращение (`onboarding_completed=True` и `last_active_date < today`)

Показывается «С возвращением, {name}!» + строка прогресса + nav_buttons.
