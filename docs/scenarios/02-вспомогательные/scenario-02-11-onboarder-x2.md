# 02.11 Сценарий входа Онбордера (знакомство с сообществом)

> **WP-406 Ф5.** Онбордер (DP.ROLE.067) доводит нового человека до состояния
> «Первокурсник»: закрывает понимание сообщества (Х2) и выбор траектории (Х3).
> Этот сценарий — про вход и срез Х2 (мини-тест понимания). Срез Х3 (выбор курса)
> описан в потоке Диагноста и оффера курса.

---

## Обзор

| Параметр | Значение |
|----------|----------|
| Триггер входа | Кнопка «🎓 Освоиться» (`callback_data=onboarder_start`) |
| Где появляется | После `/start` (Экран B быстрого пути), в приветствии вернувшегося, после ответа Проводника в Гермесе (на онбординг-вопросы) |
| Гейт показа | `offer.should_offer`: есть открытый разрыв Х2/Х3 И не на cooldown (3 дня) |
| Шаги Х2 | 3 пункта teach-confirm, без fail-state (WP-406 Ф21 — «нормы общения» сняты как непользующий пункт) |
| Результат | Отметка `x2_completed_at` + предложение перейти к выбору курса (Х3) |

---

## 1. Кнопка входа «Освоиться»

Текст и кнопка — единый источник `core/onboarder/offer.py:offer_payload()`. Решение
«показывать ли» — `offer.should_offer(chat_id)` (открытый разрыв + cooldown). Точки
показа: Экран B (`handlers/onboarding.py`), приветствие вернувшегося, и Гермес для
младшего тира (`handlers/hermes.py`, только на онбординг-релевантные вопросы по
ключевым словам — частный вопрос кнопку не вызывает).

Нажатие → `on_onboarder_start` → `core.onboarder.handle()` выбирает первый открытый
разрыв: Х2 (если не закрыт) раньше Х3.

## 2. Мини-тест Х2 (teach-confirm)

3 пункта (`core/onboarder/x2.py:X2_TOPICS`): что за сообщество · что твоё, что не
твоё · куда обращаться. По каждому пункту:

1. Короткая ориентация + кнопки «Понятно ✓» / «Подробнее».
2. «Подробнее» → расширенный абзац + «Понятно ✓» (fail-state нет: низкий ответ не
   «проваливает», доставляет недостающее).
3. «Понятно ✓» → пункт фиксируется в `current_context['onboarding']['x2_confirmed']`,
   показывается следующий.

Прогресс отображается как `(N/3)`. После 3/3 — отметка `x2_completed_at`
(`storage.mark_x2_done`, idempotent) + поздравление + кнопка «➡️ Выбрать курс»
(если Х3 ещё открыт) → тот же вход Онбордера, который уводит в Х3.

## 3. Достижимость (зачем кнопка в нескольких местах)

Новый человек по быстрому пути `/start` НЕ проходит старый пошаговый экран
(`confirming_profile`), где раньше жила единственная кнопка перехода к Х3 — поэтому
оба среза были недостижимы. Кнопка «Освоиться» в точках реального входа закрывает
этот разрыв. Cooldown 3 дня не даёт повторять оффер на каждом `/start`.

## 4. Связанные артефакты

- Обещание: `DP.SC.170` (Онбордер). Роль: `DP.ROLE.067`.
- Код: `core/onboarder/` (`offer.py`, `x2.py`, `x3.py`, `storage.py`, `handle()`).
- Хендлеры: `handlers/onboarding.py` (вход + callbacks Х2), `handlers/hermes.py` (гибрид).
- Не входит (follow-up): проактивный нудж scheduler, вынос текстов Х2 в i18n.
- **Известный дрейф (WP-406 Ф21):** `DP.SC.170`/`DP.ROLE.067` в Pack всё ещё
  описывают критерий закрытия Х2 как «4 базовых вопроса», включая нормы
  общения. Pack не синхронизирован с этим изменением — отдельное решение.
