# 02.17 `/mentor_consent` — согласие на сохранение переписки для наставника

> Участник даёт (или отзывает) согласие на то, что бот сохраняет его
> переписку — группу потока и личный чат с ботом — для наставника. Без
> согласия текст не сохраняется вообще, пишется только факт события
> (`CHECK text_requires_consent` на уровне схемы). Разбор решения:
> `DS-my-strategy/inbox/WP-578/DRR-f2-telegram-bridge.md` §5.

---

## Обзор

| Параметр | Значение |
|----------|----------|
| Команда | `/mentor_consent`, только в личке (private) |
| Вид | Вспомогательная (B) — команда → две инлайн-кнопки → подтверждение, без FSM |

| Важно | Команда НЕ вызывается автоматически при первом сообщении участника — только по явному запуску (принцип наименьшей удивлённости: участник, пришедший к ИИ-консультанту WP-498, не должен получать неожиданный вопрос про наставника) |

## 1. Flow

```
1. Участник (в личке с ботом): /mentor_consent
2. Бот показывает текст + две кнопки: [✅ Да, согласен] [Отозвать]
3. Нажатие «Да» → set_consent_grant(account_id, "mentor_archive_dm", True)
                   set_consent_grant(account_id, "mentor_archive_group", True)
   Оба scope сразу одной кнопкой — не спрашиваем раздельно про группу и личку.
4. Подтверждение: «✅ Согласие зафиксировано.»
   ИЛИ нажатие «Отозвать» → granted=False для обоих scope →
   «Согласие отозвано — новая переписка сохраняться не будет.»
5. Новые сообщения после этого момента пишутся в архив с текстом
   (consent_at_write=true) или без текста (consent_at_write=false) —
   снимок согласия берётся на КАЖДОЙ записи, не разово.
```

## 2. Сообщение бота (текст согласия)

```
Наставник вашего потока сохраняет переписку (группу и личные сообщения
боту), чтобы быстро отвечать с учётом истории. Согласны?

[✅ Да, согласен]  [Отозвать]
```

## 3. Как участник узнаёт о команде

**Известное ограничение (не забытый случай, см. `process-19`):** deep-link
из дисклеймера группы не реализован — `/start` уже занят онбордингом.
Дисклеймер группы (следующий шаг Ф2) текстом указывает участнику команду
`/mentor_consent` напрямую вместо кликабельной ссылки.

## 4. Отзыв согласия задним числом

Отзыв НЕ удаляет уже записанный текст прошлых сообщений — гасит только
запись новых. Удаление по запросу участника — отдельный контракт (РП-554,
right-to-be-forgotten), не эта команда.
